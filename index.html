Automatic model: David Lorenz Light Pollution Atlas, VIIRS 2025. The atlas models zenith brightness, not observed Bortle class. The Bortle equivalent is an approximate conversion; actual sky conditions can differ.

What goes into your score?

Clouds 40% · Moon 15% · sky darkness 15% · humidity 10% · wind 10% · visibility 10%.

Daylight, rain and overcast skies limit the score. This is a planning guide, not a success probability. Visibility does not measure astronomical seeing.

CONNECT YOUR PROJECT

Read the planner’s score and conditions from Python, a dashboard, or your own local project.

Local API

Available on this computer while Astro Tour is running.

Loading API settings…

The endpoint returns the selected location and time from the planner. Moving the time slider changes the API response too. Local access only, with a Bearer key. Keep the key in your own project; do not publish it.

Python quick start

No extra packages needed · Python 3

  1. Enable the API above and load a location’s forecast in the planner.
  2. Copy the example into astro_score.py.
  3. Run python astro_score.py while Astro Tour stays open.

The copied example includes your local API key. HTTP 401 means the key is missing or invalid; 503 means the planner has no complete score yet. Check partial to see whether light pollution is included.

Response format

JSON · GET /v1/score

{
  "score": 78,
  "partial": false,
  "mode": "live",
  "location": {"latitude": 52.23, "longitude": 21.01},
  "conditions": {"cloud_cover_percent": 12, "temperature_c": 8.5},
  "selected_time": "2026-11-06T20:00:00.000Z"
}

Illustrative values. The actual response also includes hourly weather time, Moon and Sun altitude, sky brightness, score components and application version. Weather updates hourly; the clock updates every second.
